# 分区规范 · 断点 / 台账 / 待办 / 时间线

四个区各回答一个问题：**下一步做什么**（断点）、**已经发生了什么、凭什么**（台账）、**还剩什么、谁卡着**（待办）、**什么时候变的**（时间线）。
写混了就会出现「断点里全是过程、台账里全是感觉」。

---

## 1. 断点（breakpoints）

**判据**：一个不认识你、没有你这份对话记忆的人，读完这一条就能动手，且知道怎么算做完了。

**每条三件套**：
1. **动作**：动词开头，一句话。「定插画基准母版」而不是「画风这块」。
2. **落点**：文件路径 / 命令 / 接口，具体到能直接打开或执行。
3. **验收**：怎么算做完。可观测、可复现（产出几个文件、哪个参数要相等、肉眼比哪几处）。

**颗粒度**：一条断点 = 一个 15–60 分钟内可完成的动作。大于这个范围就拆，小于就并。

**条数**：文件顶部最多 3 条；分区内可以更多，但**按优先级排序**，第一条必须是「下一个动作」。

**反例 → 改法**：
- 「继续推进画风」→「用 baseline 提示词出 3 张候选图存到 `style\cand\`，缩到 320px 并排比对，把差异写进 `style\baseline.md`」
- 「修一下字幕」→「修第 17–19 条字幕时间轴偏移（现为 +0.4s），改完用播放器核 3 处口型对齐」
- 「等用户确认」→「等 EXAMPLE_USER 从 3 张候选里挑 1 张；挑完把文件名写进 `style\chosen.txt`，我再批量出图」
- 「上次说到合成」→ 过程不进断点，过程进时间线。

**禁止**：写心路、写「继续」「优化」「完善」这类没有落点的词、写没有验收方式的动作。

---

## 2. 台账（ledger）

**判据**：每一条都能被第三方复核。「已完成」三个字不构成台账。

**每条四件套**：项 / 状态（已交付·进行中·受阻·未开始）/ **证据** / 记录时间。

**证据必须是可回查物**：
- 文件：`audio\raw\lesson01`（mtime `2026-03-02T19:12+08:00`，42 个片段）
- 日志：`logs\norm-2026-03-02.log` 末行 `ok 42/42`
- 命令输出：`ffprobe` 报 `duration=12.4`
- 校验：`sha256=…`
- 外部：URL + 抓取时间

**颗粒度**：一条 = 一个可交付物或一个可观测状态。不要把一次会话写成一条「今天做了切片、归一化、字幕、合成」。

**反例 → 改法**：
- 「切片脚本已完成」→「`scripts\slice.py` 已跑通第 1 课，产出 `audio\raw\lesson01` 共 42 段（mtime …）」
- 「字幕差不多了」→「`lesson01.srt` 已出 42 条；17–19 条时间轴 +0.4s 偏移，状态改为进行中」
- 「环境没问题」→ 不给证据就别记，环境类写进断点的验收里。

---

## 3. 待办（todos）

**判据**：有 owner、有阻塞项、有完成标准。

**每条四件套**：事项 / owner（人还是 agent，用占位名）/ 阻塞项（没有就留空）/ 完成标准。

**两分类，必须分开**：
- **可自解**：换端口、装依赖、改配置、重跑脚本——agent 自己能推进。
- **须人工卡点**：扫码登录、审批、真机验收、拍板选型——只出码、清障、验收，不自动代替。

**反例 → 改法**：
- 「TODO: 出图」→「出第 1 课 42 段插画｜owner EXAMPLE_AGENT｜阻塞：基准母版未拍板｜完成标准：42 张落在 `frames\lesson01\`，文件名与片段号对齐」
- 「音乐待定」→「决定旁白是否加背景音乐｜owner EXAMPLE_USER｜阻塞：版权清单未核｜完成标准：在 `decisions.md` 写下加/不加与理由」

---

## 4. 时间线（timeline）

**判据**：只记**状态变化点**——决策、交付、失败、恢复、交接。不记每一步操作。

**每条两件套**：ISO 时间 + 一句话事件（+ 可选类型：决策/交付/失败/交接）。

**顺序固定正序**（最早的在上），新增追加到末尾。

**反例 → 改法**：
- 「10:01 打开文件」「10:05 改了一行」→ 这些不是状态变化，删掉。
- 「2026-03-02T11:30+08:00 音频切片粒度定为句子级（决策）」
- 「2026-03-02T18:40+08:00 字幕对齐发现 17–19 条偏移（失败）」
- 「2026-03-02T21:40+08:00 本轮收工，断点已写（交接）」

---

## 5. 跨会话接续的读取顺序

新会话接手时：**顶部断点 → 待办里的阻塞项 → 台账里状态非「已交付」的条目 → 时间线最后三条**。
读完这四处就够开工，不需要通读全文。
